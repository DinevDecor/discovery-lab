Според мен Claude отново е на правилната посока.

Само една забележка бих направил: не бързай с инсталацията, ако вече използваш Claude в VS Code.

Помня, че вече работиш с Claude във VS Code по Project Memory. Ако това е същата среда, първо провери дали всъщност вече нямаш Claude Code или еквивалентната функционалност. Няма смисъл да инсталираш втори инструмент, ако настоящият върши същата работа.

Иначе самият урок, който е предложил, ми харесва много. Всъщност това е първият истински урок за Repository-driven AI, а не за поредния AI инструмент.

Аз бих продължил точно по този план:

1. Отваряш Project Memory repository.
2. Пускаш read-only ориентацията.
3. Получаваш Repository Orientation Report.
4. Даваш доклада едновременно:
    * на мен за независим review;
    * на Claude за последваща работа.
5. Едва тогава започвате да пишете код.

Това е много добра дисциплина и напълно съответства на архитектурата, която изграждаш.

Единственото, което бих променил в целия процес, е да започнете да водите “AI Capability Journal”.

След всеки урок записвайте само по една страница:

* Каква нова способност научих?
* Какъв проблем решава?
* Кога бих я използвал?
* Какво не трябва да правя с нея?
* Един реален пример от Project Memory или Dinev Decor.

След 10–15 такива урока няма просто да си “научил Claude” или “научил ChatGPT”. Ще имаш собствен наръчник за работа с AI, изграден върху реалните ти проекти. Предвид целта ти да развиваш Project Memory и КОД, мисля, че този дневник ще се окаже също толкова ценен, колкото самите прототипи.
