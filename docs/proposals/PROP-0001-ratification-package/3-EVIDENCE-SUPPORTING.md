# Deliverable 3 — Evidence Supporting Ratification

Every item below is either already in `PROP-0001` itself (cited, not
restated as new) or drawn from real work completed since, in this same
repository, under documents this package does not modify.

## From `PROP-0001` itself

1. **Already survived an adversarial review.** Verdict
   `APPROVE WITH MINOR CHANGES`, all six found risks fixed in place,
   none requiring the Variant A/B/C decision to reopen (`Adversarial
   Review — vFinal`, Part 3).
2. **The recommended variant's evidence basis is concrete, not
   speculative**: two real precedents of Observatory-shaped work
   already happening ad hoc (`project-memory/notes/2026-07-19-...`,
   `2026-07-24-...`); an independently-verified fact that KOD, GDE, and
   trust-engine are structurally unaware of each other; and a live,
   real finding (trust-engine's 60-document/15-module
   specification-vs-implementation gap) produced *during the same
   investigation* that recommends the role — the mechanism's value was
   demonstrated, not just argued for.
3. **Deliberately narrow scope.** Variant B is read-only and
   proposal-only everywhere it touches another repository — the
   source document's own self-critique confirms "fully reversible,
   since nothing is deleted or mutated outside discovery-lab itself."
4. **A named, bounded first experiment already exists**, fully
   specified and ready to run the moment a mandate is ratified
   (`Ecosystem Health Review v0.1`) — fixed scope (5 repositories, no
   dynamic discovery), fixed criteria (`C1`–`C3`), a frozen verdict
   rubric, and explicit conditions stating what result would
   *invalidate* the recommendation — a genuinely falsifiable first
   test, not a foregone conclusion dressed as an experiment.

## From work completed since `PROP-0001` was drafted

5. **The mandate's practical shape is already validated by real
   operation**, even though never formally ratified: `AG-002` (7 real
   runs) and `AG-003` (3 real curation passes, all 4 Reality Stress
   Test datasets `PASS`, one real executed pilot via `EXEC-001`) have
   operated for weeks inside exactly the kind of bounded,
   evidence-cited, human-gated discipline `PROP-0001`'s Shared Ground
   Rules and Principle 0 describe — the mandate is not an abstract
   proposal asking to be trusted on faith; its operating style has
   already been exercised and independently reviewed (`GOVERNANCE.md`'s
   full Freeze Lifecycle) without producing a single confirmed
   boundary violation (`AG-003/STATUS.yaml`: `boundary_violations: 0`).
6. **`ARCH-002`'s reconciliation found `discovery-lab`'s own governance
   mechanisms (Formal Gate, Human Final Authority) independently
   converge with `project-memory`'s and `kod`'s already-ratified
   equivalents** — `discovery-lab`'s operating model is not an outlier
   invention; it is structurally consistent with two other repositories'
   already-accepted architecture (`G2/1-UNIFIED-CONTROL-PLANE-
   SPECIFICATION.md`).
7. **`EXEC-001` demonstrated the mandate's own governance chain works
   end-to-end on a real case**: a real proposal, an independently
   reviewed Formal Gate pass, a real, dated Human Decision, and a real
   filed artifact — the exact "propose, never impose, human decides"
   shape `PROP-0001`'s Principle 0 requires, exercised for real, not
   only specified.
8. **Ratifying resolves, rather than defers, the ecosystem's own
   top-ranked risk.** `ARCH-001` (`R1`), `ARCH-002` (`G5`), and `G2`'s
   own closing note all independently name "Roles `FROZEN` on an
   unratified mandate" as the single highest architectural risk in the
   ecosystem. A ratification decision — in either direction — is the
   only action available that actually closes this risk rather than
   restating it a fifth time.
