## Why this is not a valid Contradiction Report subject, as currently evidenced

`../../ai-organization/employees/AG-003-knowledge-curator/OUTPUTS.md`
requires a Contradiction Report to name "Knowledge Objects in tension"
where "what cannot both be true" is actually established. Constructing
the two sides here would require:

- **Object A**: "`NORM`/`DEFINITION` GRIFs never carry `confidence`"
  (`RI-2`'s stated rule — well-evidenced, direct citation).
- **Object B**: "GRIFs `RI-10`/`RI-11` are `NORM`- or `DEFINITION`-typed
  *and* carry `confidence`" — but the **typing half of this claim is
  exactly what AG-002 could not confirm**. Without a confirmed type for
  those GRIFs, Object B is not itself an established claim — it is a
  plausible reading of ambiguous evidence.

A contradiction requires **two established claims** that cannot both
hold. Here, one side (Object B) is not established — it is itself
`INSUFFICIENT EVIDENCE`. Filing a Contradiction Report on this basis
would manufacture a confirmed-sounding conflict out of a genuinely open
question, which `../../ai-organization/employees/
AG-003-knowledge-curator/LIMITATIONS.md` and `CONTRACT.md`'s Evidence
Rules both forbid ("AG-003 never overrides an `INSUFFICIENT EVIDENCE`
marking AG-002 has already recorded for the same tension").

## What this screening does instead
