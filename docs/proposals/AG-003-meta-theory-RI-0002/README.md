## A note on scope, for future readers

**This is not one of AG-003's six canonical output kinds**
(`../../ai-organization/employees/AG-003-knowledge-curator/OUTPUTS.md`:
Knowledge Merge Proposals, Relationship Proposals, Core Principle
Proposals, Contradiction Reports, Knowledge Evolution Reports, Gap
Reports). It is a one-off research deliverable, explicitly framed as
such by the requesting task ("DRAFT RESEARCH"). It changes no Knowledge
Object's `status`, proposes no merge, and does not relitigate any
existing curation decision (`KMP-0001`'s decline to merge `RI-8`/`RI-12`
and `CONTRADICTION-CHECK-0001.md`'s restraint on the `NORM`/confidence
tension are both treated here as fixed, prior findings). If research
tasks of this shape recur, formalizing a seventh output kind would
itself be a minor revision under `../../ai-organization/GOVERNANCE.md`,
requiring its own evidence-linked justification — not decided
unilaterally by this one task.
