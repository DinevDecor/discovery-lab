## Reading this table

- **Q1–Q6** hold the short verdict recorded for each of the six
  mandatory questions in that review (see `ORB-REVIEW-TEMPLATE.md` for
  the fixed vocabulary each column may contain) — this table is a
  summary; the authoritative, full detail for each review is its own
  filed document under `reviews/`.
- **Status** records whether a human has yet acted on the review (for
  example: `pending human decision`, `acted on — no status change`,
  `acted on — status changed, see subject Role's HISTORY.md`). A review
  appearing in this table does not, by itself, mean anything changed —
  see `ORB-PROTOCOL.md`'s boundaries section.
