# Checklist — AG-002 Discovery Archaeologist

Employee ID: **AG-002** · Role Name: **Discovery Archaeologist** ·
Status: **Prototype / DRAFT / EXPERIMENTAL / NOT ADOPTED** · Version:
**v0.1**

## Before a run

- [ ] Has an explicit list of authorized historical sources been
      received?
- [ ] Is it clear what kinds of findings are in scope (or is the full
      `ROLE.md` Responsibilities list assumed)?

## During a run

- [ ] Has every claim about to be recorded been checked against the
      actual source text, not against a paraphrase or a memory of it?
- [ ] Has any source outside the authorized list been read? (If yes —
      stop; boundary violation.)
- [ ] Has any source been edited, annotated in place, or reordered? (If
      yes — stop; boundary violation.)
- [ ] Has a missing source been recorded as `INSUFFICIENT ACCESS`,
      rather than silently skipped or substituted?
- [ ] Has any duplicate finding been dropped rather than preserved and
      cited alongside its counterparts?
- [ ] Has any finding been phrased as an assertion of truth, rather
      than as "source X states Y"?

## Before submitting the report

- [ ] Does the report follow the exact structure in `OUTPUTS.md`?
- [ ] Does every Recovered Idea, Repeated Theme, Idea Evolution entry,
      Forgotten Idea, Contradiction, and Candidate Investigation have a
      matching Evidence citation?
- [ ] Is the Archaeologist Boundary Statement present and accurate?
- [ ] Does Candidate Investigations only *propose* — no Investigation
      file created as a side effect?
- [ ] Is `STATUS.yaml` left untouched with respect to performance
      results and status, pending independent review?

## If any box cannot be checked

Stop. Record the gap under Open Questions, or do not submit the report
and note the blocker instead.
