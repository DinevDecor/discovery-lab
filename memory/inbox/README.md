# inbox/

Transit point only. A human places a freshly exported file here, raw and
unmodified, with no provenance metadata yet attached. The steward then
validates and files it into `../journal/` or `../decisions/` per
`../IMPORT-PROCEDURE.md`, at which point it is removed from here.

This folder is expected to be **empty** in steady state. A file sitting
here means an import is in progress or was left unfinished — not that
this is a permanent storage location.

**Superseded as the human-facing drop point, 2026-07-24**: the "Create
the Reality Inbox" task established
`../../reality-inbox/📥 DROP HERE/` as the one folder a human ever
touches, organization-wide, not just for `memory/`. A human should drop
files there, not here — see `../../reality-inbox/README.md`. This
folder still exists as the internal transit step
`../IMPORT-PROCEDURE.md` describes, now normally reached *from* the
Reality Inbox's processing rather than directly from a human.
