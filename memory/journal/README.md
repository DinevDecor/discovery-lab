# journal/

Filed, provenance-tagged mirror copies of diary/journal-type source
content — the operational analogue of what a real Google Drive diary
export would eventually land here as, once a real import happens (see
`../../docs/ai-organization/MEMORY-SOURCES/INFRA-SPRINT-01-report.md` §9
— direct Drive access remains blocked; every file here today arrived via
the manual procedure in `../IMPORT-PROCEDURE.md`).

Every file in this folder must carry the full provenance metadata block
defined in `../PROVENANCE-SYNC-SPEC.md` and a matching row in
`../source-manifest.md`. A file without both is not considered filed —
see `../IMPORT-PROCEDURE.md` step 3.
