# observations/

Findings a Role (e.g. AG-002) extracts while reading a filed source under
`../journal/` or `../decisions/`. **This folder holds AG-002's own
output, not mirrored source content** — nothing here needs a provenance
block in the `PROVENANCE-SYNC-SPEC.md` sense, since it isn't an import.

Each observation file should instead state, in its own text: which filed
source it was extracted from (by path), the run that produced it, and a
citation back to the specific passage — the same evidence discipline
AG-002's `OUTPUTS.md` already requires for a Recovery Report.
