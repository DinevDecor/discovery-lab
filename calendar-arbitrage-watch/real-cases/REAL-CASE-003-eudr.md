## Observed clock

The EU Deforestation Regulation applies on different dates by operator size, creating a dated compliance wave rather than a timeless obligation.

Primary source: European Commission — Regulation on Deforestation-free Products.
Source URL: https://environment.ec.europa.eu/topics/forests/deforestation/regulation-deforestation-free-products_en

## Calendar-arbitrage hypothesis

A temporary shortage may emerge in a specific implementation function — for example supplier geolocation data, due-diligence integration, verification, or expert capacity — as mandatory dates approach.

This is not yet one proven missing function. Multiple functions must not be collapsed into one candidate without evidence.

## Current evidence boundary

Observed:
- dated regulatory application;
- staged compliance timing.

Not yet established:
- which implementation function, if any, is scarce;
- lead-time growth;
- provider concentration;
- switching costs;
- economic consequence of late preparation;
- whether existing ERP/supply-chain vendors already commoditize the need.

## Cheapest kill test

Identify the allegedly scarce implementation function first. Then test whether capacity is actually constrained or already commoditized by incumbent software/service vendors. If there is no constrained function with rising lead time or limited slots, reject the calendar-arbitrage interpretation.

## Method discipline

No numeric Calendar Arbitrage fields are fabricated. Unknowns remain INSUFFICIENT_DATA. The case stays WATCH until a specific scarce function is evidenced.
